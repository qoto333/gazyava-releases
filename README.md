# Gazyava — выпуски

Здесь лежат установщики браузера Gazyava для Windows 10/11 и файл `update.json`,
по которому установленный браузер узнаёт о новых версиях.

Скачать последнюю версию: раздел [Releases](../../releases/latest).

Установщик пока не подписан сертификатом, поэтому Windows SmartScreen может показать
предупреждение «Неизвестный издатель». Целостность обновлений проверяется подписью Ed25519
в `update.json` и контрольной суммой SHA-256.
